# Bundle Contract

Use this reference when validating static report directories or ZIP uploads.

## Required Structure

A static report bundle must contain `index.html` at the bundle root.

Acceptable contents include:

- HTML files
- CSS and JavaScript assets generated by Quarto or the report source
- image assets
- fonts and site libraries
- search indexes and metadata files needed by the static site

## Unsafe Contents

Reject server-executable files in static report bundles:

- `.php`
- `.phtml`
- `.phar`
- `.cgi`
- other server-side executable code unless the hosting flow explicitly requires it

Reject unsafe ZIP paths:

- absolute paths
- parent traversal paths containing `../`
- empty or malformed entries

## Versioning

Use a date or release version that can be traced back to the rendered output. Do not overwrite older published versions unless the hosting system is explicitly designed to do so.
