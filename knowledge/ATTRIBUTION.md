# Curated knowledge attribution

OmicsBase code is MIT-licensed. Downloaded book text and code retain their source-specific terms; they are not relicensed as MIT. The setup command downloads the pinned repositories into an ignored local cache, retains their original files and notices, and builds a local search index.

The index is a mechanical extraction of QMD/Rmd prose and code chunks, not an evaluation or rendering of the books. Search results identify the book, exact source commit, source file URL, and the source license statements below. Author/contributor details remain available in each pinned repository.

The older internal catalog had inaccurate license labels. This manifest records the statements actually found at the pinned revisions, including disagreements between package metadata and book text. It does not resolve those disagreements or grant additional permissions.
